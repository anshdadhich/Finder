Finder v0.2.2

Memory, security & preview overhaul.

RAM:
- Fast-scrolling through previews no longer leaves the WebView2 GPU process
  holding memory forever (browser flags now force it to release); the renderer
  returns toward its baseline after scrolling stops.
- Heavy UI state (search-result rows, preview bitmap, window-glass layer) is
  dropped when the window hides, instead of being kept alive between opens.
- Preview thumbnails now decode at scaled resolution (~10-30 ms per image)
  instead of full-size, and the previous image stays visible while the next
  loads (no more "Loading..." flash between every photo).

Security:
- Vendored IPC core with verified wire contract; privileged commands are
  gated behind a runtime nonce.
- Device-path & invalid-path rejection on file/folder/open actions.
- Diagnostics channel hardened (length caps, sanitized, throttled) and the
  log file is size-capped with rotation.

Search & performance:
- File-index polling now yields to the idle OS instead of blocking startup.
- The fuzzy fallback pass runs under a strict wall-clock budget.
- Warm-start cache loads faster.

Fixes:
- Launching apps/files validates integrity at medium level.
- Cache decode no longer mis-decodes after a warm start; entries are UTF-8
  validated.
- "Start with Windows" now boots silently - the launcher stays in the tray at
  logon and opens only when summoned (hotkey / tray); existing installs are
  migrated automatically.
